# User story: doador

## Historia principal

Como doador, quero explorar causas, ONGs verificadas, campanhas individuais e bundles, entender a transparencia das iniciativas e realizar doacoes de forma consciente, segura e acompanhavel.

## Criterios de aceitacao

- O doador deve conseguir se cadastrar pelo fluxo **Sou doador**.
- O doador deve conseguir visualizar informacoes de ONGs.
- O doador deve visualizar metas, arrecadacoes, score e status de verificacao.
- O doador deve conseguir verificar evidencias de confiabilidade.
- O doador deve visualizar historico de campanhas.
- O doador deve conseguir doar para ONG especifica, campanha individual, fundo/causa ou bundle.
- O doador deve visualizar quando a doacao possui matchfunding.
- O doador deve visualizar valor doado, valor combinado por match e impacto total estimado.
- O doador deve acompanhar recibos, status de pagamento e historico de doacoes.

## Regras funcionais

- O historico de arrecadacoes deve permanecer acessivel.
- Informacoes financeiras devem ser exibidas de forma transparente.
- Relatorios publicos devem possuir data de atualizacao.
- Bundles devem mostrar ONGs participantes e regra de distribuicao dos recursos.
- Campanhas devem mostrar status, meta, progresso e prazo.
- Matchfunding deve mostrar patrocinador, multiplicador, teto e validade quando aplicavel.

## Regras de negocio

- O doador deve conseguir filtrar ONGs por causa.
- O doador deve conseguir filtrar campanhas e bundles por causa.
- O doador deve conseguir visualizar historico de campanhas.
- O doador deve conseguir ver status de verificacao.
- O doador deve conseguir verificar se as informacoes foram alteradas desde a ultima verificacao.
- O doador deve conseguir diferenciar doacao direta para ONG, doacao para campanha e doacao para bundle.

## Regras de interface

- Deve ser possivel ver historico de campanhas.
- Deve ser possivel ver status de verificacao.
- Deve ser possivel ver score e explicacao dos fatores de confiabilidade.
- Deve ser possivel ver transparencia por ONG, campanha e bundle.
- Deve ser possivel acessar recibos e relatorios apos a doacao.
